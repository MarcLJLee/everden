# 아트 인계 규약 — `sprites/extracted/` 를 어떻게 물리는가

대상: 이 폴더에서 Demo 1 을 만들고 있는 구현 세션 · 대응 브리프 **v3.18**

---

## 0. 이 문서가 낡았던 이유 — 같은 실수를 두 번 하지 않는다

2026-08-25 판은 **"이번에 들어온 것 66개 파일"** 로 시작하는 **배송 메모**였다.
그래서 사흘 만에 틀린 문서가 됐다 — 파일은 162 개가 됐고, 여기 적힌
`reveals` 는 브리프 v3.14 에서 **삭제됐으며**, "종당 16장 · E/W 미러" 는
v3.16 에서 **측면 1방향**으로 바뀌었다.

> **이 문서는 목록을 들지 않는다. 목록은 `.json` 이 든다.**
> 문서에 파일 목록을 적으면 반드시 낡는다. 여기에는 **읽는 방법**만 적는다.
> (§6.9 가 화면에 대해 내린 결론과 같다 — 사양은 글이 아니라 데이터로 넘긴다)

**설계 결정은 여기 안 적는다. `PROJECT-BRIEF.md` 의 해당 절에 적는다.**

---

## 1. 전달 채널은 이미 있다

**옮길 것이 없다. 같은 폴더다.** 설계 세션과 구현 세션이 같은 경로를 쓰고,
`CLAUDE.md` 가 진입점이며 거기에 **파일 주인 표**가 있다.

| | |
|---|---|
| 생성기 | `sprites/*.py` — **설계 세션 소유.** 고치지 말고 변경분을 블록으로 넘긴다 |
| 산출물 | `sprites/extracted/` — **그 파일을 내보낸 스크립트 소유** |
| 내보내기 | `python3 sprites/export_godot.py` 한 번이면 전부 다시 나온다 |

**PNG 를 손으로 고치지 않는다.** 아트 규칙이 코드에 박혀 있어서 다음 내보내기에 덮인다.
도트를 고치는 편이 빠르면 **고쳐서 넘기고 주인이 반영한다** (실제로 그랬던 적이 있다 — 고양이 주둥이·앵커).

---

## 2. `.json` 이 진짜 인계 인터페이스다

`extracted/` 의 **json 일곱 개**가 사양을 들고 있다. 코드에 표를 다시 쓰지 말 것 —
표가 두 군데 있으면 반드시 갈라진다.

| 파일 | 무엇을 드나 |
|---|---|
| `palettes.json` | 밤낮 팔레트 4벌 · 오버레이 틴트 · 타일 크기 · 지형 변형 개수 · 프롭↔지형 · 단서↔태그 · **이형 파츠**(§4.9) · **암수/짝 표식** |
| `ui/screens.json` | **화면 인계 규약**(§6.9). 요소마다 `art`/`text`/`count`/`keycap` · **키보드↔패드 글리프 대응표** |
| `ui/logo.json` · `ui/title.json` | 진입 화면 조각과 좌표·타이밍(§6.7) |
| `home/home.json` | 집 조각 · 사물과 그 태그·값(§2.7) |
| `weather/weather.json` | 날씨 **축**·상한·프리셋·레이어 순서(§6.8) |
| `ambient/ambient.json` | 앰비언트 생물(§3.10) · 필드 크기 · **희귀 출현 규칙**(§3.11) |

> ★ **`art` 로 표시된 자리에 라벨이 들어가 있으면 구현 실수가 아니라 인계 실패다.**
> 검수는 시안 PNG 와 실행 화면을 나란히 놓고 **글의 개수를 센다.**

## 3. 폴더가 무엇을 뜻하나

경로·이름은 `scripts/art/SpriteLibrary.gd` 규약을 따른다.
**개수는 안 적는다** — `export_godot.py` 가 끝에 세어서 출력한다.

| | |
|---|---|
| `<종 id>/` | 몸통 스트립. **가로 스트립이고 프레임 폭 = 캔버스 폭**. 눈 스타일이 다른 종은 눈도 여기 |
| `<종 id>/dimorph_*.png` | **이형 파츠**(§4.9). 몸통 위에 얹는 레이어 — 몸통 시트를 성별로 나누지 않는다 |
| `shared/` | 눈 · 표현 아이콘. **종 수와 무관** |
| `terrain/` | **파일명이 `TerrainMap` 의 지형 이름.** 변형은 가로 스트립, 프레임 폭 16 |
| `terrain/extra/` | 열린 물 · 흙 · 모래 · 물가 전이 8방향 |
| `props/` `clues/` `food/` | 지형 프롭 · 단서 · 먹이 |
| `home/` | 집 · 울타리 · 살 수 있는 사물 |
| `ui/` | 로고 · 타이틀 · 커서 · 지도 아이콘 · 암수/짝 표식 · **키캡·패드 글리프** |
| `weather/` | 이어 붙는 오버레이 타일. **디더 마스크는 정수 픽셀로만 스크롤**(§6.8) |
| `ambient/` | 잡을 수 없는 생물. 도감에 없다 |
| `player/` | **구현 세션 소유.** 생성기가 안 건드린다 |

## 4. 내보내기가 남의 것을 안 지운다 — `OWNED`

`export_godot.py` 는 예전에 `shutil.rmtree(OUT)` 이었다.
그러면 이 스크립트가 만들지 않는 `extracted/player/` 37장이 통째로 사라진다.

```python
OWNED = (...)          # 이 스크립트가 소유한 폴더만
def clear_owned():     # 그 안의 png · json 만 지운다
```

> ★ **`.import` · `.uid` 는 건드리지 않는다.** 지우면 Godot 이 UID 를 새로 발급해서
> `.tscn` 의 리소스 참조가 전부 끊긴다. 덮어쓰는 것만으로 재임포트는 일어난다.
> `.gitignore` 에서도 **일부러 빼놓지 않았다** — Godot 3 의 `.import/` 폴더와 헷갈리기 쉬운 자리다.

## 5. 아트를 지배하는 브리프 절 — 여기 요약하지 않는다

값이 바뀌면 **브리프만** 고친다. 이 표는 어디를 볼지만 가리킨다.

| 절 | |
|---|---|
| **§4.5** | 뷰 각도 — **동물은 측면 1방향**, 예산은 방향이 아니라 모션에 (v3.16 전면 개정) |
| **§4.6** | 레이어 조합 · 걷기 바운스는 노드 Y · 북향에서 얼굴 파츠를 숨긴다(**플레이어에게만** 유효) |
| **§4.9** | 암수 이형 — 파츠 레이어. 몸통을 성별로 나누지 않는다 |
| **§3.3** | 감각 — **`reveals` 는 v3.14 에서 삭제됐다.** 후각·청각 = 방향, 시야 = 보이는 거리를 늘린다 |
| **§5.4** | 지면 흔적과 공중 표시 |
| **§6.2** | 타일 16×16 · Nearest · 밉맵 끄기 · Y-sort 는 캐릭터 루트 하나 |
| **§6.3 · §6.8** | 밤낮은 팔레트 보간, 날씨는 틴트+오버레이. **날씨는 팔레트를 안 건드린다** |
| **§6.9** | 화면 인계 규약 |

### 단서 — 아직 유효한 규칙 둘

냄새와 소리는 눈에 안 보이는 것이라 **지면 스프라이트가 성립하지 않는다.**
그래서 시야 계열 단서만 지면 오브젝트가 있다(발자국 · 허물 · 물자국 …).

> **① 지면 흔적은 동료가 없어도 플레이어가 직접 본다.**
> 발자국이 땅에 찍혀 있는데 눈 좋은 동료가 있어야만 보이는 건 이상하다.
> 후각·청각은 실물이 없으니 동료가 없으면 아예 알 수 없다.
>
> **② 공중 표시는 `동료 머리 위`에 뜬다** (v3.14). **대상 위치에 띄우지 않는다** —
> 그건 몸만 안 그렸을 뿐 위치를 알려주는 **원격 표시**다.
> 대상 위에 뜨는 것은 그 대상이 **내 시야 안에 들어온 뒤**다.

## 6. 매번 걸리는 것

- **발밑 타원 그림자는 스프라이트에 없다.** 별도 노드다 — 없으면 전부 떠 보인다(§4.4)
- **지형 변형은 좌표 해시로 고른다.** 규칙적으로 고르면 **세로 줄무늬**가 생긴다(겪었다)
- **앵커는 바닥 중앙**이고 Y-sort 대상이다. `props/tree.png` 는 32×48 = 2×3 타일
- **눈 색은 종 팔레트의 인덱스 7·8** 이다. 눈 레이어를 몸통과 같은 셰이더에 통과시키면
  검은 털에서 눈이 저절로 밝아진다 — 흰 테를 두르지 않는다
- **갈무리는 11px 로 찍고 정수배로만** 키운다. 임포트에서 AA·힌팅·서브픽셀을 전부 끈다(`fonts/README.md`)

## 7. 하지 말 것

- `sprites/*.png` · `*.gif` 중 **`extracted/` 밖에 있는 것은 전부 검수 문서지 게임 애셋이 아니다**
  (`*_sheet.png` · `field_daycycle.gif` · `layers.png` …). export preset 에서 뺀다.
  `sprites_pack.zip` · `art_dropin.zip` 도 마찬가지다
- **종 이름으로 분기하지 않는다.** 지형·감각·단서·이형 전부 `tags.json` 과 위 json 표에서 나온다
- **json 의 표를 코드에 옮겨 적지 않는다.** 두 군데 있으면 갈라진다
- **문장에 키 이름을 넣지 않는다**(`[스페이스]`). 장치가 바뀌면 문장을 다시 써야 한다(§2.10)
