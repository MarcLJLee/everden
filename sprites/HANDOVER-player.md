# 넘김 — 플레이어를 새 그림으로 바꿨다

구현 세션 → 설계 세션. **`sprites/extracted/player/` 는 원래 `build_player.py` 가 굽는다.**
플레이어가 준 캐릭터 시안(양갈래 · 보라 옷 · 흰 프릴)을 받아 구현이 직접 넣었으니,
생성기에 반영하고 나면 여기 적힌 것을 확인해 주면 된다.
**원본은 `sprites/extracted/player/_original_backup/` 에 그대로 있다.**

## 무엇을 했나

받은 그림은 1744×902 의 **정면·측면·후면 3면도**였다. 캔버스는 32×48 이라 10배를 줄였다.

| | |
|---|---|
| 색 | 81,172 → **9색** (기존 플레이어가 10색이다) |
| 살결 | **단색** `(248,214,178)` — 기존 플레이어와 같은 값 |
| 키 | 캔버스를 꽉 채운다 (y1~47) |
| 안경 | **뺐다** (플레이어 요청) |
| 눈 | 몸에 안 그리고 **레이어**로 얹는다 — 그래야 표정이 산다 |

## 걸린 것들 — 다음에 또 걸릴 만한 순서로

- **살결이 네 단계면 16px 얼굴에서 얼룩으로 읽힌다.** 평평하게 한 색으로 깐다
- **팔레트를 자동으로 뽑으면 색 예산을 머리카락 갈색에 다 쓴다.** 부위마다 자리를 잡아
  손으로 잡아야 살결이 보라색으로 물들지 않는다
- **팔레트를 불투명 픽셀에서만 뽑는다.** 배경 검정을 넣으면 색이 통째로 어두워진다
- **얼굴 정리 상자를 머리 높이로 제한한다.** 살결만 보고 잡으면 목·팔까지 들어가서
  옷깃을 살결로 지운다
- **옆모습은 오른쪽을 봐야 한다** (base=동쪽, 서쪽은 `flip_h`). 받은 시안은 왼쪽을 봐서 뒤집었다
- **`idle` 은 옆모습이다.** 정지 상태는 좌우만 쓰므로 앞모습을 넣으면
  옆 눈 앵커가 앞얼굴에 찍힌다
- **몸 안의 구멍을 메운다.** 그냥 두면 풀이 비쳐 얼굴에 초록 점이 찍힌다
- **`eye_style` 이 `round` 면 종 폴더를 무시하고 공용 눈을 쓴다** (`SHARED_EYE_STYLE`).
  플레이어는 자기 눈이 있으므로 `"player"` 로 바꿨다

## 아직 없는 것

- **걷는 두 번째 칸이 없다.** 받은 시안이 정지 셋뿐이라 두 프레임이 같은 그림이다 —
  걷는 느낌은 노드 Y 바운스가 낸다. **다리 프레임 하나씩만 있으면 살아난다**
- 입 그림이 없다 (`mouth_anchor` 를 뺐다)
- `player/layers/` 의 옛 파츠는 새 그림과 안 맞는다 — 그대로 두었다
- `player.json` 의 눈 앵커를 새 그림에 맞춰 고쳤다: `eye_front [16,9]` · `eye_side [21,10]`
