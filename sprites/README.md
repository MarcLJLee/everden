# 플레이스홀더 스프라이트

`build.py` 가 전부 생성한다. 손으로 그린 것이 아니라 **BRIEF 규칙을 코드로 강제한 결과물**이다.
재미가 확인되면 이 자리에 진짜 도트를 넣는다 (BRIEF §8).

```
python3 build.py     # png/ 에 스프라이트 생성
python3 present.py   # 검수 시트 · GIF · 레이어 데모 · 팔레트 데모
```

## 코드가 지키는 규칙

- **몸통에 눈·입을 그리지 않는다.** 눈은 별도 파일이고 앵커로 얹는다 (§4.6)
- **걷기 프레임에 상하 바운스가 없다.** 다리만 바뀐다 — 바운스는 노드 Y가 낸다 (§4.6)
- **외곽선은 검정이 아니라 그 색의 어두운 톤** (§4.4)
- **북향에는 눈 레이어를 붙이지 않는다** (§4.6)
- **인덱스 컬러** — 같은 그림에 팔레트만 갈아끼우면 색이 바뀐다 (§4.3)
- **캔버스는 size_class 를 따른다** — 소 24 / 중 32 / 대 48 (`tags.json`)

## 앵커

`data/animals.json` 의 `eye_anchor` / `mouth_anchor` / `head_anchor` 는
여기 실제 도트에서 확인한 좌표로 갱신되어 있다. `head_anchor` 는 방향과 무관하게
캔버스 중앙 위이며, 아이콘은 캔버스 밖으로 나가므로 엔진에서 형제 노드로 둔다.

`build_bg.py` 가 생성하고 `present_bg.py` 가 필드 목업과 하루 주기를 만든다.

```
python3 build_bg.py     # png/bg/ 에 타일·오브젝트·단서·먹이
python3 present_bg.py   # bg_parts.png · field.png · field_daynight.png · field_daycycle.gif
```

## 타일 크기

**16×16.** 32px 캐릭터가 정확히 2타일 높이다. 소형 동물(24px)은 1.5타일.

## 하루는 세 겹으로 만든다

```
1) 인덱스 아트      변하지 않는다. 한 벌뿐이다
2) 팔레트 보간      새벽 → 낮 → 저녁 → 밤 팔레트를 t 로 섞는다. 색조 담당
3) 오버레이 틴트    전역 곱연산. 밝기·채도 담당
4) 이펙트 레이어    반딧불·안개·노을. Linear 필터, 자유 좌표 (§6.2)
5) 국소 광원        모닥불 같은 것만 Light2D. 전역 조명에는 쓰지 않는다
```

**§7의 "팔레트 교체 셰이더 위에 라이팅을 얹으면 색이 틀어진다" 걱정은
전역 조명을 Light2D 로 하지 않으면 생기지 않는다.**
팔레트를 보간하므로 시간이 이산적으로 튀지 않고 연속으로 흐른다.

## ⚠️ 단서에서 나온 구멍

`trait_to_sense` 8개 중 **지면에 실물 흔적이 있는 것은 시야 계열뿐이다.**

| 감각 | 지면 오브젝트 | |
|---|---|---|
| 시야 | 발자국 · 큰발자국 · 나무흔적 · 물자국 · 허물 | 있음 |
| 후각 | 냄새강함 · 털 | **없음** (털뭉치만 실물) |
| 청각 | 울음소리 | **없음** |

냄새와 소리는 눈에 안 보이는 것이라 지면 스프라이트가 성립하지 않는다.
그래서 `냄새표시`·`소리표시`는 지면이 아니라 **공중에 뜨는 표시**로 만들었다.

이게 오히려 감각 축에 성격을 준다:
- **시야** — 혼자서도 찾을 수 있다 (느리게). 동료가 있으면 빨라진다
- **후각·청각** — 동료가 없으면 **아예 알 수 없다**
